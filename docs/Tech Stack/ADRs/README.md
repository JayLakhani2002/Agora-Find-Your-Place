# Architecture Decision Records (ADRs)

This folder records significant architecture and tooling decisions for Agora Jobs.
Each ADR captures the **context**, the **decision**, and its **consequences** so future
contributors understand *why* a choice was made — not just *what* was chosen.

## Conventions

- **Filename:** `ADR-NNNN-short-slug.md` (zero-padded, incrementing).
- **Status:** `Proposed` → `Accepted` → (`Superseded by ADR-NNNN` | `Deprecated`).
- **Structure:** Context · Decision · Consequences (plus options/analysis as needed).
- ADRs are **append-only**: don't rewrite history. To change a decision, add a new ADR
  and mark the old one `Superseded`.
- Add a row to the index table above whenever you create a new ADR.
